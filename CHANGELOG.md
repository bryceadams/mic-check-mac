# Changelog

## 0.1.1

- Automatic updates. Mic Check now checks for new versions once a day and offers to install them; there's also Check for Updates in the panel and a toggle in Settings.
- The "Lowers output quality" hint on Bluetooth devices now appears only for headsets and earbuds, not for input-only devices such as wireless mic transmitters.

## 0.1.0

- First release: one-click input switching, per-device live meters, sound test, input lock, rename and hide devices, launch at login.
